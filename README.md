# Backend Development II

Academic repository containing backend development projects created during the Backend Development II course at Duoc UC.

The projects focus on REST API development, application security, validation, automated testing, and API documentation using Java and Spring Boot.

## Technologies

- Java 17
- Spring Boot
- Spring Web
- Spring Security
- Spring Data JPA
- H2 Database
- Maven
- JUnit
- MockMvc
- Swagger / OpenAPI
- HATEOAS
- Postman
- Git & GitHub

## Main Topics

- REST API development
- CRUD operations
- Layered backend architecture
- Data validation
- Authentication and authorization
- Role-based access control
- Automated testing
- API documentation
- HATEOAS
- HTTP status code handling
